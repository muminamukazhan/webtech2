# Advanced CSS — Flexbox & Grid (Assignment #2)

**Student:** Mumina Mukazhan
**Group:** SE-2530

## Description

This project is a multi-page website created to practice advanced CSS layout techniques — **Flexbox** and **CSS Grid** — without using floats or external CSS frameworks. Each page represents a specific task from the assignment, and all pages share a common navigation bar that allows users to move between tasks.

**Live demo:** https://muminamukazhan.github.io/webtech2/

## Pages & Tasks

| File         | Task                      | What it demonstrates                                                                                                                                        |
| ------------ | ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `index.html` | Home                      | Landing page with an overview and navigation to all tasks                                                                                                   |
| `task1.html` | Task 0 + Task 1 (Flexbox) | Flexbox navigation bar with the logo on the left and links on the right, plus a responsive row of equal-height cards with consistent gaps and hover effects |
| `task2.html` | Task 2 (Grid)             | Page layout using `grid-template-areas` with a header, left sidebar, main content area, and footer                                                          |
| `task3.html` | Task 3 (Grid)             | Image gallery using CSS Grid with equal-width columns, consistent gaps, and hover caption overlays                                                          |
| `task4.html` | Task 4 (Flexbox + Grid)   | Portfolio page combining both techniques: Flexbox for the navbar and project cards, and CSS Grid for the main content and sidebar                           |

## How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Navigate between the tasks using the navigation bar at the top of each page.

No build step or local server is required.

## Deployment

The website is published using **GitHub Pages**.

The live website is available at:

**https://muminamukazhan.github.io/webtech2/**

To deploy the project using GitHub Pages:

1. Push the repository to GitHub.
2. Open the repository settings.
3. Go to **Pages** under the **Code and automation** section.
4. Select the `main` branch and the root folder (`/`).
5. Save the settings.
6. Open the generated GitHub Pages link.
